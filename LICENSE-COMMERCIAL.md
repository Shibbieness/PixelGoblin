## When a game needs this

The PixelGoblin **runtime** is meant to be embedded in games so they can
generate sprites on the fly. A game that links the engine and ships
closed-source is the most common reason to want out of AGPL's share-alike
condition. That is exactly what this option is for.

What does **not** need a commercial license:

- Using the editor or CLI to make sprites, tilesets, or UI kits, then
  shipping those images in a closed-source game. Output is not covered by
  the engine's license.
- Open-source games that embed the runtime under AGPL.
- Individuals, students, nonprofits, jams, and small commercial users
  generally — the free path serves them.
