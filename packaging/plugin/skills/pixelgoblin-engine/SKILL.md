# Working on the PixelGoblin engine

PixelGoblin is Mark's (Shibbieness, M MAOU LLC) deterministic pixel-art engine. Version v0u1p0 (VUP versioning), engine major 0. Python standard library only, integer-only at runtime. A browser workbench runs the same engine in JavaScript, pixel-identical.

The engine source is the `pixelgoblin` skill's `engine/` folder (`../pixelgoblin/engine`). It holds the Python package, type files and flavors, but **not** the tests, tools and docs. For real engine work, use the full repository: the PixelGoblin PseudoSkill capsule (`pixelgoblin.skill`, folder `build/source/`) or Mark's repo. If neither is present, say so and ask Mark to attach the repo zip (`pixelgoblin-v0u1p0.zip`).

## Talking to Mark

Mark has dyslexia. Keep replies short and plain, with clear headings. Report results as "what changed, what was checked, what is still open".

## Standing rules

- **Nothing breaks determinism.** Same inputs, same bytes, on every platform. No floats in the runtime, no `random`, no dict-order or time dependence. Named xoshiro128** streams only.
- **Every change goes through the gates.** Run `PYTHONHASHSEED=0 python3 tests/gate.py --all` (24 build gates, B00 to B23) and `python3 tests/falsify.py` (51 mutations that must all be caught). Counts may only go up: `tests/FLOOR.json` is a ratchet.
- **Python is the source of truth for geometry and worlds.** `rig.py`, `rig3d.py`, `beast.py` and the planner in `sandbox.py` are transpiled to `editor/pg-rig.gen.js` by `tools/transpile_rig.py`. Gates B13, B22 and B23 check JavaScript parity. The transpiler supports a subset: use `g.get(k, None) is not None`, never `k in g`, for dict membership; keep tuple constants split.
- After engine changes: `python3 tools/transpile_rig.py`, then `python3 tools/build_editor.py` (builds the workbench, the Pocket and Goblin Grounds), then the gates, then `python3 tools/package.py all` to rebuild the plugin and the PseudoSkill capsule.
- **Goldens** (224) change only on purpose, re-blessed with Mark as witness. Never re-bless silently.
- **Mark's reference images (`refs/`) are never published, zipped or copied.**
- Commits: author `Shibbieness <shibbieness@gmail.com>`, no AI co-author trailers. Docs end with "—Shibbieness" and "—Claude".
- Mark's other repos are read-only; send fixes as patches.
